ModelFinder

The cheapest AI model that passes your own tests.

Audit the models your code uses, test candidates on your real prompts, and get a cheapest-first routing setup. It runs on your machine, with your keys.

Install View the source

From guesswork to evidence

Most teams pick a model once and keep paying for it. Model Finder measures what each candidate costs per passing answer on your own work, then hands you the cheapest one that clears your bar.

  1. Audit

    Finds every AI model and SDK your repository calls, and flags hard-coded model IDs that will age badly.

  2. Evaluate

    Drafts eval examples from your prompt files, then runs every candidate on them with your keys. You see pass rate, latency and cost per passing answer.

  3. Route

    Turns the results into a cheapest-first chain that falls back to a stronger model when a reply fails your checks, with a ready LiteLLM config.

Every request starts at the cheapest model that passed your evaluation.

Running models locally?

Model Finder also estimates memory for weights and KV cache at your context length, and tells you whether an open-weight model fits your GPU.

Install in your tool

Needs Python 3.9 or later. No packages to install, no account, nothing to sign up for.

/plugin marketplace add Abhiindigloo/EvalHarness
/plugin install model-finder@model-finder

Adds four skills and the local MCP server. Also works in Cowork.

# Full plugin with skills: install from the Cursor directory
https://cursor.directory/plugins/model-finder

# MCP server only, from PyPI (needs uv)
uvx model-finder-mcp==1.3.5

The directory installs skills and tools together. For tools only, add the uvx command to your Cursor MCP settings.

codex plugin marketplace add Abhiindigloo/EvalHarness
codex plugin add model-finder@model-finder
copilot plugin marketplace add Abhiindigloo/EvalHarness
copilot plugin install model-finder@model-finder
gemini extensions install https://github.com/Abhiindigloo/EvalHarness

Gemini CLI starts extension tools only in folders you trust. It asks the first time you open a project.

{
  "mcpServers": {
    "model-finder": {
      "command": "uvx",
      "args": ["model-finder-mcp==1.3.5"]
    }
  }
}

Works in VS Code, JetBrains, Windsurf, Claude Desktop and other MCP clients. Published on PyPI and in the official MCP Registry as co.indigloo/model-finder.

Your code stays yours

Built for teams in regulated sectors. Designed with India's DPDP Act in mind.

Runs on your machine
The MCP server makes no network calls and writes no files. Nothing is ever sent to Indigloo.
Your keys, your providers
Evaluations call only the providers you configure, with keys read from your environment. Keys are never printed or stored.
Personal data blocked by default
Inputs are scanned before sending. Secrets are always blocked; Aadhaar, PAN, card numbers and similar data stop the run unless you allow them.
Advice, not changes
It never switches your model or deploys anything. You review the routing it suggests and decide.
