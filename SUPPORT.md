# Support

## Get help

- **Questions and bugs:** open an issue at https://github.com/Abhiindigloo/EvalHarness/issues. Include your AI tool and version (for example Claude Code 2.1, Gemini CLI 0.64), your Python version, and what you ran. Issues are public: remove API keys, personal data and confidential code first.
- **Security problems:** do not open a public issue. Follow [SECURITY.md](SECURITY.md).
- **Privacy questions or complaints:** see [PRIVACY.md](PRIVACY.md). To raise one privately, ask in an issue for a private contact channel without including personal details.

## Before you open an issue

1. Run the tests: `python3 -m unittest discover -s tests -v`.
2. Check that `python3 --version` is 3.9 or later and on your PATH. On Windows, see the README.
3. If the MCP tools are missing in Gemini CLI, trust the project folder when prompted.
4. For eval problems, run with `--dry-run` first and include its output.

## Response

Issues are answered on a best-effort basis. There is no paid support plan.
